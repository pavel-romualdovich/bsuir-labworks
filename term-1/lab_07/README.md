# Лабораторная работа №7

**Тема:** Программирование с использованием структур.

**Задача:** Имеется список автомобилей. Каждый элемент списка содержит следующую информацию: марка, номер кузова, год выпуска, объем двигателя и максимальная скорость. Объявить структуру с заданными полями. Динамически выделить память для хранения списка структур. Реализовать операции ввода и вывода.
