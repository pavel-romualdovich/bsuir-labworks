# Лабораторная работа №15

**Тема:** Использование двусвязанных списков.

**Задание:** Создать двусвязанный список, состоящий из n целых чисел. Переместить
во второй список элементы, повторяющиеся в первом списке более одного раза.
Результат вывести на экран. В конце работы освободить всю динамически выделенную память.
