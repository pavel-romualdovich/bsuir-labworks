# Лабораторная работа №14

**Тема:** Использование стеков.

**Задача:** Создать стек, состоящий из n целых чисел. Поменять местами минимальный
и максимальный элементы стека, информационную часть в оперативной памяти не перемещать.
Результат вывести на экран. В конце работы освободить всю динамически выделенную память.
