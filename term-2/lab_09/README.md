# Лабораторная работа №9

**Тема:**
Программирование с использованием функций.

**Задача:**
Вывести на экран таблицу значений функции и ее разложения в ряд для x, изменяющегося от a до b с шагом h = (b – a) / 10. Расчет y(x) и s(x) поместить в функцию. Использовать прототипы функций. Параметры передавать по указателю. Расчет функции s(x) выполнить с заданной точностью EPS.
